# Exercises of the personalised practice: ONE block per rule of the corpus (app/rag/rules); a line with three equals signs splits blocks.
# Lines (each rule has at least one `choice` and one `fix`; `fill` is optional; there may be several of each):
#   choice: prompt | the correct option FIRST | wrong option | wrong option   (the order is shuffled when served)
#   fill:   sentence with ___ | answer / other accepted answer
#   fix:    sentence with the mistake | corrected sentence / other accepted correction
# The speaking exercise is made from every `fix`: say the corrected sentence (the first accepted one).
# Original sentences, written for this project. Each exercise has exactly one right answer.
